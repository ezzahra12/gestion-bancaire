# 🏦 NexaBank — Gestion bancaire digitale

Application console Java permettant de gérer les opérations bancaires.

## 📌 Description

NexaBank est une application développée en **Java** dans le cadre d'un projet individuel.

L'application permet de gérer les clients, leurs comptes bancaires et les différentes transactions.

## 🚀 Fonctionnalités

* Gestion des clients
* Création et gestion des comptes bancaires
* Dépôt
* Retrait
* Virement
* Consultation du relevé bancaire
* Historique des transactions
* Sauvegarde des données dans des fichiers `.txt`
* Gestion des exceptions

## 🛠️ Technologies utilisées

* Java
* Maven
* Programmation Orientée Objet (POO)
* HashMap
* HashSet
* Fichiers `.txt`
* UML
